# Duplicate Line Remover

A fast, private, browser-based tool for removing duplicate lines from pasted text.

## Features

- Removes repeated lines instantly in the browser
- Keeps all text local with no uploads or server processing
- Optional case-sensitive matching
- Optional whitespace trimming
- Optional blank-line removal
- Optional alphabetical sorting
- Live cleanup statistics for input, unique, duplicate, and empty lines
- Copy result and clear controls
- Light and dark theme support

## Run Locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deployment

This project is ready for static hosting on GitHub Pages or any static web host.

## Privacy

All processing happens locally in the user's browser. The app does not upload, store, or send pasted text anywhere.
